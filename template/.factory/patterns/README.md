# 可复用需求 Pattern

Pattern 描述已经稳定、可以重复执行的一类完整产品需求。它不是代码模板，也不是把需求拆碎的依据。

首次需求使用 `bootstrap`；人工校准若干次后可进入 `supervised`。只有连续干净交付达到 Pattern 中的
条件，且没有人工修改、验证拒绝、逃逸缺陷或越界，才可由人类批准升为 `trusted`。`trusted` 只省略
方案确认，最终合并始终由人类完成。

新建 `<pattern-id>.json`，并按 `../pattern.schema.json` 填写适用条件、允许变化、必须保持的不变量、
验证证据、晋级条件和降级信号。不要复制某个业务项目的数据到另一个项目。
