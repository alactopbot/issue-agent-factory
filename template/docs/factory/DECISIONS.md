# Factory 决策记录

记录已获人工批准的流程、Pattern 和约束变化。新记录置顶，必须引用真实 Issue、PR、Check 或交付证据。

## 模板

### YYYY-MM-DD：决策名称

- **变化：** 规则前后有什么不同。
- **证据：** 支持决定的真实执行与结果。
- **接受的风险：** 什么更可能发生。
- **重新评估条件：** 出现什么观察时撤销或调整。

## 初始原则

- 一个完整产品需求一个 Issue、一个分支、一个 PR。
- Draft/Ready 表达方案决定，最终合并表达产品验收。
- Pattern 渐进成熟，人工合并始终保留。
- 实现与验证使用不同 Codex 上下文。
- 范围不设置文件数或代码行数阈值。
